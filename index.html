Home Assistant Calendar Integration

This is a personal, noncommercial integration used to display Google Calendar events on a privately operated Home Assistant dashboard.

Privacy Policy

The integration accesses Google Calendar data only after the Google account owner authorizes access through OAuth.

Calendar data is used to display events and support calendar functionality within the owner's Home Assistant installation.

Calendar data is not sold or used for advertising. Access can be revoked through Google Account security settings.

The Home Assistant installation and its connected integrations are managed privately.
